### 2. Recommended Reading Order for Peers (To Learn & Understand)

To understand how LB-UNet works from theory to implementation, read the files in this order:

```
1. lbunet.py ➔ 2. dataset.py ➔ 3. boundary.py ➔ 4. utils.py ➔ 5. engine.py ➔ 6. config_setting.py ➔ 7. train.py & test.py
```

| Order | File | What to Focus On |
| :---: | :--- | :--- |

| **2nd** | [`dataset.py`](file:///c:/Users/HP/Downloads/MIP/dataset.py) | **Data Pipeline**: Understand `NPY_datasets` — notice how training loads 3 items per sample (`image`, `mask`, `points_boundary`), while validation loads 2 items (`image`, `mask`). |
| **3rd** | [`boundary.py`](file:///c:/Users/HP/Downloads/MIP/boundary.py) | **Boundary Generation**: See how edge extraction (`Get_edge`), contour finding (`findContours`), and genetic algorithm optimization select the best boundary keypoints along the lesion perimeter. |
| **4th** | [`utils.py`](file:///c:/Users/HP/Downloads/MIP/utils.py) | **Loss & Visualization**: Inspect `GT_BceDiceLoss` (combines binary cross-entropy + Dice loss across main output, boundary maps, and deep supervision layers) and `save_imgs()` (creates 3×5 grid comparison figures). |
| **5th** | [`engine.py`](file:///c:/Users/HP/Downloads/MIP/engine.py) | **Execution Logic**: Review `train_one_epoch()` (forward pass, loss calculation, backward step) and `test_one_epoch()` (computes mIoU, Dice/F1, Sensitivity, Specificity). |
| **6th** | [`config_setting.py`](file:///c:/Users/HP/Downloads/MIP/config_setting.py) | **Configurations**: View dataset settings, image resolution (`256x256`), optimizer (`AdamW`), learning rate scheduler (`CosineAnnealingLR`), and data augmentations. |
| **7th** | [`train.py`](file:///c:/Users/HP/Downloads/MIP/train.py) & [`test.py`](file:///c:/Users/HP/Downloads/MIP/test.py) | **Entry Scripts**: High-level runners that orchestrate the pipeline from end to end. |
